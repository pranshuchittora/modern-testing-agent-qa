## About

This repository aims to build a **comprehensive, well-organized, and multi-level** knowledge base for software testing, covering:

| Category | Description |
|----------|-------------|
| **Open Source Tools/Frameworks** | Test automation tools, platforms, and frameworks |
| **AI + Testing** | LLM testing, AI-powered test generation, intelligent test analysis |
| **Best Practices** | Industry-leading test repositories and enterprise practices |
| **Learning Resources** | Books, blogs, courses, and conferences |

## Resource Criteria

Resources added should meet the following criteria:

1. **Activity**: Active maintenance with updates in the last 6 months
2. **Quality**: Clear documentation and community support
3. **Impact**: Stars > 100 or industry use cases
4. **Relevance**: Strongly related to software testing
5. **Openness**: Open source or free to use
