## 推荐工具详情

### k6

> **官方文档**: [https://k6.io/docs/](https://k6.io/docs/)

**基本信息**

| 属性 | 说明 |
|-----|------|
| **维护者** | Grafana |
| **首发时间** | 2016 |
| **脚本语言** | JavaScript/TypeScript |
| **许可证** | AGPL-3.0 (CLI) / SSPL (Cloud) |
| **GitHub Stars** | [24k+](https://github.com/grafana/k6) |

**特性**

- 开发者友好的 JS 脚本
- 高性能，基于 Go 和 JS V8
- 与 Grafana 集成，可视化强大
- 支持 HTTP/2, WebSocket, gRPC
- 云原生，支持 Kubernetes
