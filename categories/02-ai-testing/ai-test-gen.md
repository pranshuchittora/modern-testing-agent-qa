## 开源工具

### TestGen-LLM

> **GitHub**: [microsoft/TestGen-LLM](https://github.com/microsoft/TestGen-LLM)
>
> **论文**: [TestGen-LLM: Code-Designed Test Generation using Large Language Models](https://arxiv.org/abs/2406.19359)

| 属性 | 说明 |
|-----|------|
| **维护者** | Microsoft Research |
| **类型** | 测试用例生成工具 |
| **GitHub Stars** | ![GitHub Repo stars](https://img.shields.io/github/stars/microsoft/TestGen-LLM?style=social) |

**特性**

- 结合 LLM 和符号执行
- 支持复杂输入生成
- 高代码覆盖率
- 与 pytest 集成

**标签**

`#test-generation` `#llm` `#microsoft` `#python` `#pytest`

> **GitHub**: [lucifer1993/apollo](https://github.com/lucifer1993/apollo)
>
> **论文**: [Apollo: An Autonomous LLM-based Agent for Test Generation](https://arxiv.org/abs/2405.14335)

| 属性 | 说明 |
|-----|------|
| **类型** | 自动化测试生成 Agent |
| **GitHub Stars** | ![GitHub Repo stars](https://img.shields.io/github/stars/lucifer1993/apollo?style=social) |

**特性**

- 全自动测试生成流程
- 自我反思和改进
- 支持多语言
