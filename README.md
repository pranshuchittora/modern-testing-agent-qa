## 项目定位

本仓库旨在构建一个**综合、全面、分层**的软件测试领域知识库，涵盖：

| 内容类型 | 说明 |
|---------|------|
| **开源工具/框架** | 测试自动化工具、测试平台、测试框架 |
| **AI + 测试** | 大模型测试、AI 测试用例生成、智能测试分析 |
| **优秀实践案例** | 业界领先的测试仓库、企业级实践案例 |
| **学习资源** | 测试相关书籍、博客、课程、会议 |

## 资源筛选标准

添加的资源需满足以下条件：

1. **活跃度**: 项目有持续维护，近 6 个月有更新
2. **质量**: 有清晰的文档和社区支持
3. **影响力**: Star 数 > 100 或有业界应用案例
4. **相关性**: 与软件测试强相关
5. **开放性**: 开源或提供免费使用
